Generation speed and elastic accuracy

Lower generation time and lower FEA energy error are better. Each case keeps its own results. Equal grid resolution does not mean equal element count.
What this benchmark measures

FEA accuracy

The same linear tetrahedral elasticity solver handles every valid mesh, with E = 1 and Poisson ratio 0.3 in normalized coordinates. Exact quadratic displacement fields supply body forces and natural boundary tractions. Six pins per connected component remove rigid motion. Six affine patch tests and free-equilibrium checks must pass.

The main score is the worst relative strain-energy error over every linear combination of 18 quadratic displacement fields. This is a fixed load family, not a guarantee for every engineering problem. The exact field is integrated on each generated polyhedral domain. Geometry approximation remains a separate diagnostic.

Performance and admission

Generation time includes Microgen case construction, extraction, remeshing or Meshers generation, and owned-array conversion. It excludes imports, process startup, geometry validation, FEA and file writing. Repeats use fresh processes and rotating backend order. Warmups are retained but excluded from medians.

The direct MMG binding uses one volume-adaptation pass on VTK tetrahedra with physical box-cap triangles fixed. Microgen MMG calls its public two-pass remesher through the installed MMG command wrapper, including file exchange and retries. Both use hsiz = L / intervals and hgrad = 1.3. Specimens are non-periodic. Meshers profiles change only the optimization-pass budget. No failed run falls back to another algorithm or a weaker quality threshold.

The MMG shape metric q is normalized to 1 for a regular tetrahedron. Low q alone does not exclude a VTK/MMG FEA result. Numerical comparisons require global mesh checks, affine patch tests, equilibrium, the declared sampled geometry tolerance and the material-volume tolerance. Sampled implicit residual divided by gradient is a first-order distance estimate, not a Hausdorff certificate. Interior overlap checks have declared floating-point tolerances and a checked work cap. Geometry-invalid and incomplete runs remain visible.
