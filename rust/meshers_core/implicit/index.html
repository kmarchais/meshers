Functions§

adapt_intersection
Adapt a conforming nonperiodic Tet4 seed using the same physical fields. Mask bits identify the supplied fields. The seed must pass a separate sampled seed_tolerance; final quality and geometry use options without relaxation. The caller owns the seed’s topology and resolution of disconnected features.
generate
Generate a closed solid boundary and conforming tetrahedra directly from a field. Custom functions and grading use the same evaluator in roots, optimization and refinement. Unmet sampled tolerance or invalid topology returns an error, never a partial success.
generate_with_constraints
Adapt an equivalent retained intersection. Periodic and quadratic feature contexts are not admitted by this interface.
generate_with_features
Generate with optional equivalent max-of-affine hints for adaptive Tet4. The complete plane set must have matching traces on requested periodic ends. Hints must describe the same negative sublevel set. Hints whose normalized coefficients are unrepresentable retain scalar behavior.
generate_with_regions
Generate a Tet4 union of intersections using equivalent affine hints. Periodic regions require adaptation and certified complete end traces. Region masks select nonpositive planes; callers own hint equivalence.
generate_with_size
Generate with an optional positive spatial target length for tet adaptation. Geometry sizing and gradation remain active. Periodic size traces must match.
periodic_affine_region_traces
Conservative complete-region trace certificate for a union of intersections. Each conjunction of normalized restricted planes must have an exact end match. Periodic seed nodes and cap facets still require independent validation.
periodic_affine_traces
Whether finite affine hints certify equal complete max-field traces at the ends. This is conservative: each restricted affine equation must have an exact match. A matching trace does not certify that a generated seed has matching cap facets.
