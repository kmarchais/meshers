meshers_core

Module accelerator 

Source
Expand description

Experimental optimizer adapter contract. No device dependencies in the core. Factories create an engine per immutable-topology optimization stage. Engines return one displacement per group in color order. Groups in a color have no shared tetrahedra. Implementations with device acceptance must perform the same float64 geometry, inversion and quality checks as CPU acceptance before returning displacements. They are trusted numerical extensions, not a safe way to accept arbitrary unvalidated vertex moves.
